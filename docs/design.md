# MiniHUD 设计

日期：2026-11-05

## 目标

制作一款 Windows 游戏性能叠加层。默认在左上角显示极简小黑卡：FPS、CPU 温度、GPU 温度、显存已用/总量。设置窗口可逐项开关内存、SSD 温度与读写速度、网络上传与下载速度，以及现有的帧时间、CPU/GPU 利用率等指标；另有电脑配置页。优先支持无边框窗口游戏，界面不注入游戏进程。

## 实现

基于 `andrei-cb/fps_monitor` 的 AGPL-3.0 C++/Win32 源码扩展。保留许可证与来源记录，使用其 ETW 帧率、NVML GPU、PawnIO CPU 温度和无注入叠加层实现。默认关闭自动安装 PawnIO 驱动；CPU 温度不可读时显示无数据及原因，驱动安装须单独经用户确认。

新增 Windows 原生采集器：`GlobalMemoryStatusEx` 读取内存；`GetIfTable2` 计算活跃网卡收发速率；PDH 读取所有物理磁盘的总吞吐；`IOCTL_STORAGE_QUERY_PROPERTY` 尝试获取存储设备温度。硬盘不提供温度时只显示 N/A，不编造数值。隐藏指标不采样。配置页按需读取 CPU、GPU、内存、磁盘和 Windows 信息。

## 界面

默认卡片使用深黑色不透明底、白色数字、低对比度标签、统一字号与细间距。默认四项单行显示，左上角紧贴屏幕边缘（默认边距 0 像素）；可设置每行指标数量，点击穿透。开启更多指标时卡片按固定列宽增加行数。设置窗口提供指标开关、位置、透明度、缩放、快捷键和传感器状态；电脑配置为独立页。

## 验收

在本机验证 FPS 采集状态、NVML GPU 数据、CPU 温度可用性、内存、SSD 温度/读写和网速；启动无边框游戏验证可见性与点击穿透。分别测量程序空闲和显示卡片时的私有内存、CPU 占用，统计所有辅助进程。输出可运行程序和缺失传感器的明确原因。
