# MiniHUD 1.0 收尾范围

用户确认：不做每游戏配置；修复录制独立采样、缺失数据、内存增长和无用低帧计算；增加可配置录制热键、录制红点、指标拖动排序。新版本验证后发布源码、EXE、安装包与 ZIP，删除旧发布版本，保留提交历史。

实现：
- 录制按 1Hz 流式 CSV；全程帧统计改用固定约 125KB 分桶直方图（分位数近似，均值精确）；保存释放缓存，重复停止不覆盖已生成报告。
- 录制强制采样报告所需传感器，缺失项显示无数据；录制锁定渲染进程。
- 低帧独立开关和采集掩码；开启时最多每两秒更新，关闭后缩短帧缓存、释放过大队列。
- Ctrl+Shift+F11 开始/停止，设置可改；小黑条显示录制红点，不增加刷新计时器。
- 设置支持拖动指标排序并保存，旧配置无新字段仍兼容。
- 版本统一 1.0。保留当前官方在线下载并校验 PawnIO 的方式，不内嵌旧安装器。
