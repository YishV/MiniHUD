# 英文指标、猫咪图标、登录自启动

用户确认：设置保持中文，指标语言可切换；英文使用简洁常见标签。原创奶白线条猫替换所有 EXE/托盘图标。启动项默认关闭，仅由设置中的用户操作启用或关闭。

实施与验证：
1. Config 保存 EnglishMetrics，指标渲染选择中文/英文标签；验证重载与两种布局。
2. SVG 作为图标源，GDI+ 脚本生成多尺寸 ICO 和预览；小尺寸增加线条粗度。
3. startup_task 独立负责 Windows Task Scheduler COM。以用户 SID 命名当前用户任务，交互式 HighestAvailable，登录延迟 8 秒；命令和目录以 XML 转义、无 shell 拼接。
4. 设置打开时查询系统真实状态。勾选注册、取消删除；操作失败显示错误，程序移动提示更新路径。恢复显示默认值不改动系统启动项。
5. 主程序编译、配置和中英文布局测试、ICO 帧结构检查；使用普通用户权限的 Windows Task Scheduler 任务定义对象解析 XML，核对权限、交互式登录与电池设置；查询真实状态，不注册或开启自启动。实际创建任务与登录触发未测试。
