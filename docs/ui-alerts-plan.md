# 中文界面、布局与告警

已确认范围：界面中文，默认左上角单行，多行时每行 1–8 项；不增加延迟。

实现顺序：
1. 配置加入布局版本和逐项阈值，旧配置首次迁移左上角，保存后尊重用户的位置选择。
2. 用统一指标渲染替代默认特例，单行/多行共用告警规则；无数据不告警，屏幕放不下时自动换行。
3. 加载 Windows 中文字体，设置分为显示、告警、电脑配置三个中文页。
4. 定向验证阈值边界、禁用、配置保存/重载、旧配置迁移；编译并打包。

默认提醒阈值：FPS <45、帧时间 ≥33.3ms、CPU 占用 ≥95%、CPU ≥90℃、GPU ≥85℃、SSD ≥70℃、内存/显存 ≥90%。GPU 利用率、功耗、磁盘和网络速度默认不告警（0），用户可设置；这些值不是硬件安全上限。
